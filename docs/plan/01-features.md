# 기능 카탈로그

> (← [README](README.md) · 아키텍처는 [03-server-architecture.md](03-server-architecture.md))
>
> 개정일: 2026-09-11
>
> ⚠️ **우선순위 태그의 의미가 바뀌었다.** 이전 태그(`MVP`/`MVP+`/`후순위`)는 **OSS 공개 런칭**을
> 기준으로 한 것이었다. 무료 공개가 없어진 지금 기준선은 **"첫 고객 계약에 필요한가"** 이다.
> - `계약` — 없으면 팔 수 없다
> - `확장` — 계약별 요구로 들어오면 만든다
> - `후순위` — 수요 확인 전까지 안 만든다
>
> **구현 상태(§0)가 우선순위 태그보다 항상 우선한다.** 태그는 목표, §0은 사실이다.

## 0. 구현 상태 (2026-09-11 기준)

### ✅ 구현됨 — 제품
- **디바이스**: 업서트·멀티디바이스·메타(locale/timezone/country)·무효토큰 자동정리(전송응답 unregistered)
- **Identity**: `identify`·유저 속성·`identity_hash`(HMAC) 검증
- **메시징**: 개인(single)/토픽/세그먼트/broadcast, 예약발송(`scheduled_at`), 딥링크, A/B **변형 분배**, 카카오 폴백 플래그
- **억제리스트**(opt-out) · **In-app 인박스**(조회/읽음) · **Quiet hours**(프로젝트 UTC)
- **세그먼트**(속성 동등 매칭) · **저니**(명시적 enroll + send/wait) · **카카오 알림톡 폴백**
- **웹훅**(HMAC 서명 + 원자적 재시도) · **분석**(디바이스 활동/DAU·발송 집계) · rate limit
- **멀티테넌시**(Org→Project, env 분리, 프로젝트별 Firebase 격리·AES-GCM)
- **SDK**: core/web/react/react-native + android(Kotlin)/swift/flutter · **MCP**(5 tools) · OpenAPI 문서 · **log-only 모드**
- **콘솔**: 28개 화면, 전 화면 페이지 전환 스켈레톤, API 문서 iframe 임베드
- **i18n**: next-intl **25개 로케일** (ko → en → 로케일 병합)

### ✅ 구현됨 — 배포/상용 (§O)
- Ed25519 **라이선스** 발급·오프라인 검증
- **로그 리텐션 purge** · **`/ready` 헬스게이트** · 부팅 시 필수 env 검증
- **업데이트 서버**(우리 인프라) — 채널·고객별 pin·차단·yank
- **업데이터 사이드카** — 백업 → 마이그레이션 → 교체 → 확인, 조건부 자동 롤백
- **폐쇄망 번들** — `.tar` + `.sha256` + 메타, 체크섬 없으면 설치 거부
- **릴리스 CI** — 다이제스트 고정, `hasMigrations` 저널 자동 판정, 멀티아치, cosign
- **지원 번들** — 값 없이 설정 **유무**만

### 🔜 미구현
- 익명→식별 병합, 선호센터, 템플릿 변수치환(스키마만), Rich push(이미지/버튼)·silent/data·우선순위·TTL·다국어 콘텐츠
- A/B **승자 자동선택**, 전달추적(delivered/opened/clicked/dismissed)·읽은 유저 목록
- WAU/MAU·GeoIP 지역분석·토픽 증감·퍼널·코호트·CSV export
- 빈도제한(fatigue)·발송시간 최적화(유저 타임존)·이벤트 트리거 푸시·In-app 메시지(배너/모달)·액션 버튼
- realtime(Centrifugo)·친구톡·멀티채널 워터폴·미리보기·발송승인·마이그레이션 임포트·화이트라벨·RBAC·감사로그
- idempotency·DLQ·OS 네이티브(채널/뱃지/그룹/사운드)·llms.txt·OpenAPI→SDK 자동생성·AI 카피·GDPR export/삭제

### 🔴 `계약` 태그인데 **미구현** — 판매 전 결론이 필요한 항목

태그는 "없으면 팔 수 없다"는 뜻인데 §0에 없는 것들이다. 만들거나, 태그를 내리거나 둘 중 하나다.

| 항목 | 상태 | 판단 |
|---|---|---|
| 템플릿 **변수치환** (§C) | 스키마만 있음 | 개인화를 파는 순간 필요. 마케팅 성격 고객이면 필수 |
| **테스트 발송** (§I) — 내 폰 먼저 | 없음. `/tester`는 **API 테스터**로 다른 기능이다 | 오발송 방지 장치. 대량 발송 고객에게는 사실상 필수 |
| **graceful shutdown** (§K) | 없음 | 무인 업데이트 전제 |
| **백업/복구 런북** (§O) | 덤프는 되나 **복구 절차 문서 없음** | 인수인계 산출물 |

### ⚠️ 부채 (기능 아님, 차단 요인)
- **graceful shutdown 미구현** — 무인 업데이트의 전제 조건
- **rate limit 인메모리** — 다중 인스턴스에서 한도가 인스턴스 수만큼 곱해짐
- 저장소가 아직 **Apache-2.0** 선언 중 (README 「라이선스 표기 불일치」)

## A. 디바이스 라이프사이클
- 토큰 관리·업서트 · **멀티디바이스**(유저=여러 기기) `계약`
- 메타: OS/앱버전·기종·**locale·timezone·region** `계약`
- 토큰 로테이션·로그인/로그아웃 재매핑 · last-active · 채널(android/ios/web/webview/electron) `계약`
- **무효 토큰 자동정리**(전송응답 unregistered) `계약`
- **앱 삭제/이탈 감지** `확장` — ⚠️ "silent로 실시간"이 아니라 **전송응답 기반 무효화 + 이탈률 지표**

## B. 유저 / Identity ⭐(핵심 차별점)
- **identify**(외부 유저ID 매핑) · **유저 속성/태그** `계약`
- 익명→식별 **병합**(로그인 시) `확장`
- **알림 선호센터**(토픽/카테고리 opt-in) `확장` — GDPR·개인정보 심사에서 요구될 수 있음

## C. 메시징
- **개인/세그먼트/토픽 발송** `계약`
- 템플릿 + **변수치환** `계약` — ⚠️ **토픽 브로드캐스트는 개인화 불가**(수신자별 개별 렌더링 필요)
- **Rich push**(이미지·버튼·딥링크) · silent/data · 우선순위 · TTL/collapse `확장`
- **딥링크** `계약` — payload `deep_link` + 네이티브 Universal/App Links
- 예약 발송 `계약`(구현됨) · A/B 승자선택 `확장` · 반복 캠페인 `후순위`
- 다국어 콘텐츠(로케일별) `확장`

## D. 전달 추적
- sent/delivered/**opened**/clicked/dismissed `확장`
- **메시지·토픽별 읽은 유저 목록** · 유저별 전달상태 `확장`
- 실패 사유 · 전환추적(open→이벤트) `후순위`

> 전달 추적은 이전에 `MVP`였다. 실제 계약에서는 **발송이 되는가**가 먼저 검증되고
> 추적은 2차 요구로 들어오는 경우가 많아 내렸다. 마케팅 성격 고객이면 `계약`으로 올린다.

## E. 분석
- **DAU** `계약`(구현됨) · WAU/MAU · **지역 분석**(GeoIP/locale) · 토픽 증감 `확장`
- 오픈/클릭률 · 전달 퍼널 · 이탈률 · 코호트 · 히트맵 · CSV export `확장`

> **CSV export는 온프렘에서 자주 요구된다.** 고객이 자기 BI로 가져가려 한다.

## F. 타게팅
- **세그먼트**(속성 동등 매칭 구현됨, 행동·지역 규칙 미구현) `확장`
- **Quiet hours** `계약`(구현됨) · 빈도 제한(fatigue) · 지역 타게팅 · 발송시간 최적화 `확장`

## G. 자동화 / 참여
- **이벤트 트리거 푸시** `확장`
- 저니/워크플로 `확장`(기본 구현됨)
- **In-app 인박스** `계약`(구현됨) · In-app 메시지(배너/모달) `후순위`
- 알림 액션 버튼 `확장`

## H. 채널
- push(FCM) · **Web Push** · **WebView**(네이티브 브리지) `계약`
- realtime(Centrifugo — 상시연결) `후순위`
- **카카오 알림톡 폴백** ⭐(국내) `계약`(구현됨) · 친구톡 `확장`
- 멀티채널 워터폴(push→카카오→SMS→email) · APNs 다이렉트 · HMS `후순위`

## I. 운영 편의
- **테스트 발송**(내 폰 먼저 → 오발송 방지) `계약` ⭐
- **억제 리스트** `계약` ⭐
- 미리보기 · 템플릿 라이브러리/버전 `확장`
- **발송 승인 워크플로**(결재) `확장` — 규제·공공에서 요구될 수 있음

## J. 플랫폼 / 멀티테넌시
- **Org → Project** 계층, 크로스 프로젝트 대시보드 `계약`(구현됨)
- **환경 분리(dev/staging/prod)** `계약` — 프로젝트별 키
- **마이그레이션 임포트**(OneSignal/FCM) `확장` — 도입 마찰↓, 교체 영업에 직접 쓰임
- **화이트라벨** `확장` — 에이전시·SI 재판매
- **RBAC · 감사로그** `확장` — ⚠️ **ISMS·공공 조달에서 사실상 필수.** 해당 고객이 오면 `계약`

## K. 인프라 / 신뢰성
- rate limit `계약`(구현됨, ⚠️ 인메모리) · idempotency · 재시도+**DLQ** `확장`
- **웹훅**(HMAC + 재시도) `계약`(구현됨, DLQ 없음)
- OS 네이티브: 알림 채널/카테고리 · 뱃지 동기화 · 그룹/스레드 · 사운드 `확장`
- **graceful shutdown** `계약` ⚠️ **미구현 — 무인 업데이트 전제 조건**

## L. 개발자 경험
- **SDK 매트릭스**: core / web / react / react-native / android / swift / flutter `계약`(구현됨)
- webview(+Capacitor·Cordova) / electron `확장`
- **서버 내장 MCP** `확장`(구현됨 — 5 tools)
- **OpenAPI-first** → 문서·MCP 단일 파생 `계약`(구현됨)

## M. AI 기능
- **AI 카피라이팅** `확장`
- ML 발송시간 예측 · 세그먼트 자동제안 · 자동 번역 `후순위`

## N. 컴플라이언스
- 수신거부/opt-out `계약`(구현됨)
- **GDPR export/삭제 · 동의 추적 · 데이터 리텐션 정책** `확장` — ⚠️ 규제 고객이 오면 즉시 `계약`

## O. 배포 / 상용 ⭐(신규 — 클로즈드 전환으로 생긴 축)

이전 기획에는 없던 영역이다. **제품 기능이 아니라 판매 가능 조건**이다.

- **라이선스** — Ed25519 오프라인 검증, 만료는 업데이트만 차단 `계약`(구현됨)
- **업데이트** — 콘솔 원클릭, 다이제스트 고정, 마이그레이션 강제 `계약`(구현됨)
- **폐쇄망 번들** — 반입 설치, 체크섬 강제 `계약`(구현됨) — 금융·공공 필수
  - ⚠️ **폐쇄망에서 API 문서 화면이 렌더링되지 않는다.** Redoc을 `cdn.redoc.ly`에서 받는다.
    폐쇄망을 필수 요건으로 파는 이상 번들에 포함하거나 제약으로 명시해야 한다
- **지원 번들** — 값 없이 설정 유무 `계약`(구현됨) — 온프렘 진단의 유일한 수단
- **백업/복구 런북** `계약` — 마이그레이션 전 자동 덤프는 구현됨, **문서가 없다**
- **버전 표시** — 전 화면 푸터 `계약`(구현됨)
- **로그 리텐션 purge** — `LOG_RETENTION_DAYS`, 워커 야간 배치 `계약`(구현됨)
  - ⚠️ **미설정이면 안 지운다.** 인수인계 시 보존 기간 합의 필수
- **`/ready` 헬스게이트** — DB 왕복 확인. 업데이터가 교체 후 이걸로 성공 판정 `계약`(구현됨)
- 롤아웃 카나리 `확장`
- 원격 모니터링(옵션 agent) `후순위` — ⚠️ **폐쇄망에서 동작하지 않음.** 팔기 전에 전제를 확인할 것

## 설계상 꼭 지킬 노트
1. **앱 삭제 감지** = 전송응답 unregistered 기반(실시간 100% 아님)
2. **개인화(이름 치환)** = 수신자별 개별 발송에서만, 토픽 브로드캐스트 불가
3. **A/B** = Firebase Remote Config ❌(앱설정용), **서버사이드 메시지 A/B** ⭕
4. **딥링크** = payload 직접링크. OneLink/FDL 불필요 — 푸시는 이미 설치된 유저에게 간다
5. **지역** = GeoIP(서버) + locale/timezone(SDK). LB 뒤라 `X-Forwarded-For`
6. **라이선스 한도** = 표시만, 집행 안 함. 초과로 발송을 막으면 계약 분쟁이 고객 서비스 장애가 된다
