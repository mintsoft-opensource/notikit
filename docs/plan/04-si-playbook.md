# SI (구축 의뢰) 플레이북

> 제품 사다리 최상단: OSS(무료) → BYOC 구독 → **SI(엔터프라이즈/공공 구축)**.
> 고접점·고단가·저확장. **표준화·반복가능**하게 만드는 게 마진의 핵심.
> (← [README](README.md) · [02-deployment-service.md](02-deployment-service.md))

## 1. 진행 7단계 (산출물)
| 단계 | 할 일 | 산출물 |
|---|---|---|
| **1. 발굴·요구분석** | 플랫폼·볼륨·기존인프라(FCM/APNs)·유저모델·규제(ISMS/GDPR) | 요구정의서, 프로파일(S/M/L) |
| **2. 견적·계약** | 범위·일정·수용기준 | **SOW** + 견적 + 계약(변경관리 조항) |
| **3. 설계** | 환경 맞춤(서버/DB/도메인/TLS), 통합설계(인증→identify, API키, SDK), 마이그레이션 | 아키텍처·통합·보안 검토서 |
| **4. 환경 구축** | 프로파일 설치(compose/Helm), DB/Redis/realtime/로그, 크레덴셜, 백업·모니터링·TLS | 구축 환경 + 구성문서 |
| **5. 통합** | 앱 SDK 통합(또는 고객팀 지원), identity·토픽·템플릿·웹훅 연결 | 통합 완료, 연동 테스트 |
| **6. 테스트·UAT** | 플랫폼별 발송·부하테스트(사이징 검증)·장애/재시도 → 인수테스트 | 테스트 결과서, UAT 승인 |
| **7. 오픈·인수인계** | 컷오버, 대시보드, **런북**(백업/복구/업그레이드), 관리자 교육 | 인수인계서 + 유지보수 계약 |

## 2. 계약·과금
```
구축비(1회)      : 설계+구축+통합+테스트 (규모별)
+ 라이선스/구독  : BYOC 컨트롤플레인 or 상용기능 (연간)
+ 유지보수(연간) : 통상 구축비의 10~15%/년 (업데이트·모니터링·장애대응·SLA)
```
- **재발 매출 = 유지보수·구독**. SI 일회성만으론 불안정.
- 한국 관행: 구축비 + 유지보수율(10~15%) + 공공은 조달/보안심사(ISMS).

## 3. 반드시 피할 함정
1. **커스텀 포크 지옥** — 고객마다 코어 갈라 고치면 유지보수 폭탄. → **config/plugin 확장점**으로 흡수, 코어는 OSS 유지, 유용한 커스텀은 업스트림 병합.
2. **스코프 크립** — SOW 밖은 **변경요청(CR)** 별도 과금.
3. **비반복 구축** — **표준 딜리버리 키트**(체크리스트·설치스크립트·프로파일·런북)로 반복가능하게 → 마진 확보.
4. **IP/라이선스** — 코어 Apache-2.0 유지, 커스텀 소유권 계약 명시.

## 4. 제품 사다리 연결
- OSS = 발견·신뢰(무료 유입) → SI 리드 소스
- BYOC 구독 = 셀프서브 중형
- **SI = 대형/공공/규제** → 최고 단가, 유지보수 재발매출
- SI에서 만든 **표준 키트/플러그인**이 제품 강화 → 선순환

## 5. 한 줄
> **요구분석→SOW→설계→구축→통합→UAT→인수인계+유지보수** 7단계 표준화. **코어 포크 금지(config/plugin 흡수)**, **구축비+유지보수(10~15%)+구독**, **딜리버리 키트로 반복가능**하게.
